# Sales & Revenue Analysis Dashboard

An interactive Sales & Revenue Analysis Dashboard built using Python, Pandas, Plotly and Streamlit.

## Project Overview

This project analyzes sales data and presents important business insights through an interactive dashboard.

The dashboard allows users to explore sales performance based on different regions and product categories.

## Features

- Total Sales KPI
- Total Profit KPI
- Total Quantity KPI
- Total Orders KPI
- Revenue Trend Analysis
- Region-wise filtering
- Category-wise filtering
- Interactive Plotly visualizations

## Technologies Used

- Python
- Pandas
- Plotly
- Streamlit

## Dataset

The project uses a sales dataset containing information such as:

- Order ID
- Order Date
- Product
- Category
- Region
- Customer Segment
- Quantity
- Unit Price
- Discount
- Sales
- Profit
